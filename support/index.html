本ページでは今後、書籍・機材などのアフィリエイトリンク（広告）を掲載する場合があります。掲載時には該当箇所に「PR」と明記します。

このサイトを応援する

RT-Lab は、ひとりの放射線技師が運営している無料・広告なしのWebツール集です。すべてのツールはブラウザ内で完結し、入力データを外部に送信しません。サーバー費用やドメイン維持などの運営コストを、読者のみなさんの応援で支えていきたいと考えています。

お約束：ツールは今後も無料で提供し、ページ内に業務を妨げるディスプレイ広告は表示しません。応援はあくまで任意です。

☕ 投げ銭で応援する

「役に立った」と感じたら、1杯のコーヒー程度のご支援をいただけると運営の励みになります。

☕ 投げ銭で応援 準備中

📚 おすすめ書籍・機材で応援する PR

放射線技師の学習・業務に役立つ書籍や機材を、アフィリエイトリンクで紹介する予定です。同じ商品を購入される際にこちらのリンクを経由いただくと、価格はそのままで運営費の一部になります。

📚 おすすめを見る 準備中

📝 note で深掘り記事を読む

ツールの使いこなしや、造影プロトコル設計・線量最適化などの実務ノウハウを note で解説していく予定です。有料記事の購入も応援につながります。

RT-Lab は、現役の放射線技師が個人で企画・開発・運営しています（プライバシー保護のため氏名は非公開）。ツールへのご要望・不具合のご連絡は お問い合わせ（GitHub Issues）からお寄せください。
